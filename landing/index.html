Meet the agents doing the work

Each stage of a credential's path is run by a named agent, not a black box. You can point to the step that's running and the agent running it.

Verifier Agent

Live

Runs primary-source verification on every document a candidate submits — checked against the issuing institution, not just read and filed.

  • Extracts and cross-checks every field against the source
  • Flags inconsistencies before a human ever sees the file
  • Learns your criteria from every file it processes

94% first-submission acceptance, against a ~60% industry standard for manually-prepared files

Regulator Agent

Live

Interfaces directly with the destination licensing authority — submission, status tracking, and resubmission if a regulator comes back with a request.

  • Speaks each regulator's own submission format
  • Tracks status per authority, not per spreadsheet row
  • Files nothing until the Verifier Agent has cleared it

11 regulators live behind this one agent — SCFHS, DHA, GMC and more, added without a new integration each time

Trust Agent

Pilot

Manages the compliance layer around getting a verified professional into place — the part that runs after the credential clears and before they start work.

  • Keeps every party's compliance status current, not just the file's
  • Anchors the cleared credential on an immutable ledger
  • Runs on the same white-labeled layer as the other two

Pilot running with early customers ahead of general availability
